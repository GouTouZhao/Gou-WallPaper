## 🌟 项目简介

**Gou Wallpaper** 是一款专为 Windows 10 与 Windows 11 (64位) 打造的专业桌面壁纸与原生屏幕保护程序管理软件。

针对本地海量 4K / 8K 高清静态大图（PNG、JPG、WebP、BMP、TIFF）进行了底层内存优化与降采样渲染，彻底解决了传统壁纸软件占用高、长时间运行内存泄漏、休眠后计时器失效、重启丢失进度以及看视频时屏保误弹切屏等痛点。Gou Wallpaper 提供**不放回随机洗牌轮播**、**双模式长短周期高可靠调度**、**多显示器独立壁纸**、**自适应网格拼贴**，并交付符合 Windows 原生调用标准的 `.scr` 屏幕保护程序与系统级智能防打扰。

## 🚀 核心优势

### 1. 极低内存开销与大图按需解码
- **毫秒级极速扫描**：扫描文件夹阶段仅读取图片头部元数据（耗时 < 1ms），绝不将大图像素一次性全部读入内存；
- **目标分辨率按需降采样**：仅在实际设定壁纸或播放屏保时，根据当前物理显示器的实际分辨率进行高质量抗锯齿解码与有界 LRU 缓存；
- **后台物理工作集自动释放**：主窗口最小化至系统托盘或进入纯后台守护时，自动触发系统级 Working Set 内存整理，常驻内存占用极低，轻巧流畅不卡顿。

### 2. 双模式高可靠轮播调度系统
彻底解决传统壁纸软件长时间运行失效、电脑休眠后时钟漂移、关机重启丢失进度的工程痛点：
- **短间隔调度（切换间隔 < 6 小时）**：
  - 基于高精度单调时钟（`time.monotonic`）精准触发，毫秒级响应；
  - 具备睡眠唤醒补偿：电脑休眠唤醒后自动核算真实时间漂移，若跨越计划周期则立即执行补偿切换。
- **长周期调度（切换间隔 ≥ 6 小时，如 6h、12h、每日一图、每周一图）**：
  - 基于持久化带时区的 **UTC 系统时间戳**（`last_success_at_utc`, `next_due_at_utc`）进行跨周期严格校准；
  - 采用轻量轮询器比对真实系统时间，绝不使用脆弱的一次性长定时器，绝不通过累加轮询次数推算时间；
  - **重启智能单次补偿**：关机重启或开机自启后，若预定时间已过，执行且仅执行一次平滑补偿，绝不连续闪屏刷图；
  - **原子落盘与故障退避**：配置文件保存采用临时文件写入 + 原子替换，壁纸设置异常时自动指数退避重试。

### 3. 系统级多媒体智能防打扰（彻底杜绝看剧/游戏误触发屏保）
- **WASAPI 核心音频电平检测**：通过 Windows Core Audio 实时检测硬件音频输出（视频播放器、音乐软件、浏览器刷抖音/B站/YouTube、语音通话）；
- **25 秒智能平滑冷却期**：短视频换集间隙或电影短暂停顿时绝不误弹屏保；
- **全屏与独占应用识别**：自动感知 DirectX 独占 3D 游戏、PPT 投影演示模式以及前台物理全屏窗口；
- **主动重置系统空闲倒计时**：媒体播放期间自动向 Windows 操作系统申报保持显示常亮（`ES_DISPLAY_REQUIRED`），从源头阻止 Windows 自行切入屏保黑屏桌面，彻底杜绝“屏幕突然黑一瞬间”的现象。

### 4. 智能电源管理与定时自动睡眠
- **屏保常亮防息屏**：屏保轮播期间可选择保持屏幕点亮，避免欣赏壁纸时被系统强行熄屏；
- **定时自动睡眠/熄屏**：支持设置屏保运行 10 分钟、15 分钟、30 分钟、1 小时、2 小时后，自动调用系统底层电源接口执行**系统睡眠**或**关闭显示器（息屏省电）**，节能环保无忧。

### 5. 纯本地离线与隐私保护
- **零网络依赖与零遥测**：所有配置、元数据索引与图像处理均在本地离线执行，不收集任何用户隐私数据；
- **非破坏性处理**：对壁纸的缩放、拼贴、微调绝不修改或覆盖本地原始图片文件。

## 🎨 主要功能一览

| 功能模块 | 说明 |
| :--- | :--- |
| **图片库管理** | 支持添加多个本地图片文件夹，支持递归扫描子目录、启用/禁用开关、去重校验，50 项虚拟化分页流畅浏览。 |
| **支持图片格式** | 完整支持 `PNG`、`JPG/JPEG`、`WebP`、`BMP`、`TIF/TIFF`，自动过滤动态 GIF 与损坏文件。 |
| **壁纸轮播模式** | 支持**不放回洗牌随机轮播**与**顺序轮播**，快捷预设 1 分钟 ~ 1 周，支持精确到秒的自定义间隔。 |
| **多显示器管理** | 支持多屏拓扑识别，各屏幕独立壁纸设置，支持跨屏全景 (Span)、填充 (Fill)、适应 (Fit)、拉伸 (Stretch)、居中 (Center)、平铺 (Tile)。 |
| **画面网格拼贴** | 支持 2~8 张图片自动计算最优行列网格拼贴 (Collage)，支持保存合成高清大图。 |
| **画面非破坏性微调** | 支持亮度、对比度、饱和度、色温冷暖实时微调与预览。 |
| **原生屏幕保护程序** | 交付标准的 `GouWallpaperSaver.scr`，支持 Windows 屏保面板无缝集成（`/s` 全屏、`/c` 配置、`/p` 小预览窗）。 |
| **屏保视觉动效** | 支持淡入淡出 (Fade)、平滑平移 (Slide)、微距缩放 (Zoom) 与无过渡切换，可配置切换间隔与过渡毫秒。 |
| **屏保数字时钟** | 内置极简数字时钟与日期覆盖层，支持小/中/大/特大字号及左下角/居中偏上/居中底部多位置选择。 |
| **常驻持久操作栏** | 主界面底部常驻：上一张、下一张、立即设为壁纸、暂停/继续轮播、立即随机、全屏屏保测试。 |
| **系统托盘与自启** | 支持开机自动静默后台运行（`--minimized`，写入当前用户注册表，无需提权），托盘图标右键菜单丰富。 |
| **全局快捷键** | 支持注册全局热键（如显隐桌面图标、快捷切换下一张壁纸等）。 |

## 📖 使用指南

### 1. 快速上手
1. 打开 `GouWallpaper.exe`；
2. 切换至【静态图库】选项卡，点击【添加图片文件夹】，选择存放高清壁纸的本地目录；
3. 切换至【定时调度】选项卡，选择期望的切换间隔（如 10 分钟、30 分钟、1 天）；
4. 切换至【桌面壁纸】选项卡，选择喜欢的填充布局（默认推荐“填充裁剪 (Fill)”）；
5. 点击底部【立即设为当前壁纸】即可生效。

### 2. 配置与安装原生屏幕保护程序
Gou Wallpaper 原生屏保程序完全遵循 Windows `.scr` 规范：
- **方式一（应用内一键安装）**：
  在主界面切换至【屏幕保护】选项卡，点击【注册 GouWallpaperSaver.scr 为系统屏保】；
- **方式二（系统右键安装）**：
  在文件资源管理器中找到 `GouWallpaperSaver.scr`，鼠标右键点击并选择【安装】；
- **方式三（独立配置对话框）**：
  右键选择【配置】或双击运行 `GouWallpaperSaver.scr`，即可打开独立的屏保参数配置面板，支持设置独立屏保图片文件夹、动画特效、时钟样式及定时睡眠时间。

### 3. 命令行与快捷脚本参数

#### 主程序 `GouWallpaper.exe`
```text
GouWallpaper.exe [OPTIONS]
  --minimized        以最小化模式启动，保持系统托盘静默运行
  --startup          开机自启调用模式
  --next             立即切换到下一张壁纸并退出
  --previous         立即切换到上一张壁纸并退出
  --random           立即随机切换一张壁纸并退出
  --apply            立即应用当前选中的壁纸并退出
  --check            立即检查轮播调度状态并退出
  --auto-close-ms N  (测试专用) 运行 N 毫秒后自动退出
```

#### 屏幕保护程序 `GouWallpaperSaver.scr`
```text
GouWallpaperSaver.scr [/s] [/c] [/p <HWND>]
  /s                 全屏启动屏幕保护程序 (任意按键或鼠标晃动退出)
  /c[:HWND]          打开屏保独立配置对话框
  /p <HWND>          在 Windows 屏幕保护程序设置对话框的小预览框中内嵌运行
```

## 🛠️ 源码开发与打包构建

### 运行环境
- **操作系统**：Windows 10 / Windows 11 (64 位)
- **Python**：Python 3.10 或更高版本

### 本地运行步骤
```powershell
# 1. 克隆代码并进入项目目录
git clone <repository_url>
cd GouTou-WallPapper

# 2. 创建并激活虚拟环境
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# 3. 安装依赖库
pip install -r requirements.txt

# 4. 启动主程序
python main.py

# 5. 运行屏幕保护程序测试
python screensaver_entry.py /s
```

### 运行自动化测试
项目配备了完整的自动化单元与集成测试，覆盖时钟抽象、调度状态自愈、图片格式校验、防闪黑机制与电源管理：
```powershell
pytest -v
```

### 一键打包可执行程序
使用项目内置的自动化构建流水线打包独立 EXE 与 SCR：
```powershell
python build.py
```
构建完成后将在 `dist/` 目录下生成：
- `dist/GouWallpaper.exe`（单文件独立主程序，无控制台黑框）
- `dist/GouWallpaperSaver.scr`（单文件独立 Windows 原生屏保程序）
- `release/SHA256SUMS.txt`（构建产物哈希完整性校验）
